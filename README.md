# X (Twitter) 活動時間帯チェッカー

ブラウザから直接 FxTwitter の RSS フィード（CORS対応）を取得し、直近100件の投稿時間帯（日本時間: 0〜23時）を集計するWebアプリケーションです。

サーバーやバックエンドAPI（Workers等）は不要で、静的ファイルのみで動作します。

## ディレクトリ構成

```
x-activity-analyzer/
├── index.html     # HTML構造
├── style.css      # スタイルシート
├── script.js      # データ取得・集計ロジック
├── README.md
└── .gitignore
```

## 使い方

1. `index.html` をブラウザで直接開きます（または任意の静的Webサーバーで配信）。
2. ユーザー名を入力して「分析」ボタンを押します。
3. 直近100件の投稿データをもとに、各時間の活動件数とピーク時間帯がJSON形式で表示されます。
